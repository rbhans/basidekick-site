# Modern Geometric Brand Assets

This set extends the approved BASidekick Optical Balance mark with the Signal Geometry visual language. The core mark geometry is unchanged. New personality comes from structured negative space, restrained signal routes, modular fields, and large geometric forms created specifically for this set rather than reused from the landing-page artwork.

`brand-system-board.png` presents the BASidekick and co-brand directions together for quick review.

## BASidekick

- `basidekick-banner-light.png` - 1500x500 light social or presentation header
- `basidekick-banner-dark.png` - 1500x500 dark social or presentation header
- `basidekick-square.png` - 1080x1080 square social asset

The site-wide Open Graph image at `/og.png` and the existing 1500x500 social header were updated from this same system.

## BASidekick x QA Graphics

- `basidekick-qa-banner-light.png` - 1500x500 light co-brand header
- `basidekick-qa-banner-dark.png` - 1500x500 dark co-brand header
- `basidekick-qa-square.png` - 1080x1080 square co-brand asset
- `basidekick-qa-lockup.png` - 1600x400 wide co-brand lockup

The BASidekick and QA Graphics marks remain separate and proportionally intact. Shared geometry lives around the marks, not inside them. Keep the spacing already present in these compositions when cropping or placing them in another layout.
